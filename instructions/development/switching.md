# Development scope

Before working in a repository, run the profile resolver for that target and read its repository-local AGENTS.md / CLAUDE.md, plus applicable nested instructions before editing their files. Repeat whenever the target repository changes, including from one code-root remote-control session. Do not assume startup discovery covered repositories entered later.

Work/personal grants apply only to targets classified in that environment. Guidance loaded for another target is historical context, not permission for this target. Unknown targets get no personal push/merge grants or work-specific automation grants. Classify each target separately before cross-repository work. Profiles are instruction selection, not security enforcement.

Personal frontend guidance is on demand, only for targets classified personal: read ${AI_TOOLS_HOME}/instructions/development/frontend.md only for React/TypeScript frontend work. Shared procedures may reference provider-specific skills; use an available equivalent or report the missing capability, never invent successful execution. Preserve project-local constraints and higher-priority instructions.
