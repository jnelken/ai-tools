## ai-tools checkout

The ai-tools dev checkout on this Mac is `~/Dropbox/code/ai-tools`. It is also `AI_TOOLS_HOME` and `AI_TOOLS_DEV_DIR`, so hooks, the resolver and the shell auto-sync all read the same copy and edits take effect immediately. Other machines keep their own layout; this path is a fact of this machine only.

## Spark CLI (personal Mac only)

The `spark` CLI is a thin IPC client to the Spark Desktop app and exists only on this machine. Use the `use-spark` and `scoutmail` skills here; on the work Mac, the PC and cloud sessions there is no `spark`, so do not try to run it or install it.
