# Folio Datadog Hygiene — Run Memory

Append-only log of weekly review runs. Carried over from this skill's earlier life as a Codex automation, which kept a `memory.md` alongside the automation definition.

**This file is committed, not gitignored.** The whole point of keeping run history is so a future run — on any machine, since this repo syncs skills across laptops — can tell "still persists" apart from "new this week" or "resolved since last review." Local-only memory would silently break that continuity the first time the skill runs from a different session or host. Contents are operational metadata (service names, tag values, counts, endpoint IDs) — nothing secret.

New entries go at the bottom. Keep entries factual and evidence-backed, matching the findings-table style in `SKILL.md`.
